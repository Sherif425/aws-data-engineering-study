# ✅ **Exam Overview (quick summary to guide your study plan)**

The AWS Data Engineer exam focuses on:

### **1. Data Ingestion & Transformation (35%)**

- Kinesis Data Streams / Firehose
- MSK / Kafka on AWS
- AWS Glue (ETL jobs, Glue Studio, Glue Workflows)
- AWS Lambda ETL
- Amazon SQS

### **2. Data Storage & Management (30%)**

- S3 (Storage classes, lifecycle, performance)
- DynamoDB (capacity modes, Streams, DAX)
- Redshift (RA3, Spectrum, Workload management)
- RDS / Aurora for OLTP
- Lake Formation

### **3. Data Modeling, Analytics, & Orchestration (25%)**

- Redshift schema design
- Athena partitions, CTAS, performance
- Glue Data Catalog
- Step Functions
- EMR fundamentals

### **4. Security, Access Control, Monitoring (10%)**

- IAM permissions
- Encryption (KMS)
- CloudWatch, CloudTrail, logging
- VPC networking basics for data services
